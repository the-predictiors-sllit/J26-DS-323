# Mulin meka kiyawanna

1. Me ZIP eka extract karala, athule `kithmini` folder eka balanna.
2. Oyage original project eka backup karagena, me updated files adala
   `experiments/kithmini` folder ekata copy/merge karanna. Mulu original folder eka
   delete karanna epa: oyage best_model.pt / last_model.pt me ZIP eke naha.
3. `models/best_model.pt` thiyenawada balanna. Kalin download karapu eka use karanna;
   file paths hadapu nisa aye train karanna one naha.
4. `README.md` eke backend commands kithmini root eke terminal ekakin run karanna.
5. Aluth terminal ekakin frontend folder ekata gihin `npm ci`, `npm run dev` karanna.
6. http://127.0.0.1:3000 open karanna. Model ready nam original photo ekak dala mask ganna.
7. Model evaluation tab eke results/deeplabv3/run_20261008_01/test_metrics.json select karanna.
8. Buttons wala colour wenas karanna frontend/components/ui/button.tsx balanna.
   `docs/UI_STYLING.md` eke blue -> green example eka thiyenawa.

Me package eke CNN dataset bytes saha reviewed masks naha. Draft masks 17 thiyenawa.
Reviewed masks oyama editor eken hadala masks/reviewed folder ekata save karanna.
Kalina results/test_metrics.json eka dan results/deeplabv3/run_20261008_01/ athule.
Merge kalama parana duplicate results/test_metrics.json ekak ithuru unoth, aluth path
ela thiyena copy eka samanada balala duplicate eka ain karanna puluwan.

Colab notebook eka fresh run ekakata hadala thiyenawa. train.py + model.py + CNN.zip
witharai upload karanne. Final evaluation pasuwa full backup download karanna.
Dan thiyena model eka use karanna notebook eka aye run karanna awashya naha.
