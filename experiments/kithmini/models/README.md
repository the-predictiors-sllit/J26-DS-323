# Inference model

Place the trained `best_model.pt` here and restart FastAPI. It is deliberately
absent from this review ZIP and ignored by Git. The API resolves this path relative
to backend.py, so moving the whole kithmini folder does not change the default.

Use the downloaded Solar_Training_Backup.zip from the recorded experiment,
or obtain the agreed copy from the component owner. No public download URL has
been supplied. Record the shared location and SHA-256 when the team chooses one.
`last_model.pt` belongs with the original run results and is for training resume.
